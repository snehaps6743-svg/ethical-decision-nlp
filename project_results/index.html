Ethical Decision Making Using NLP

Artificial Intelligence | Natural Language Processing

An NLP-based system for detecting bias and supporting fair decision-making.

1. Project Overview

This project uses Natural Language Processing (NLP) to analyze decision statements and identify whether a decision is ethical or unethical.

The system also detects possible types of bias and provides a fair recommendation to support ethical decision-making.

2. Objective

  • Detect whether a decision statement is Ethical or Unethical.
  • Identify possible types of bias in the decision.
  • Provide a fair recommendation for biased decisions.
  • Compare traditional machine learning with a transformer model.

3. Models Used

  • TF-IDF + Logistic Regression – used as the baseline model for ethical classification.
  • DistilBERT – used as the transformer model for Ethical/Unethical classification.
  • TF-IDF + Logistic Regression – used for detecting the type of bias.

4. Dataset

A custom labeled dataset containing ethically relevant decision statements was developed for this academic prototype.

The dataset contains 296 decision statements.

Bias Categories

  • Age Bias
  • Gender Bias
  • Disability Bias
  • Cultural/Ethnic Bias
  • Language Bias
  • No Bias

8. Model Comparison

The project compares a traditional TF-IDF based machine learning approach with the DistilBERT transformer model.

  • TF-IDF converts text into numerical features.
  • Logistic Regression performs classification.
  • DistilBERT uses contextual language representations.

11. Advantages

  • Identifies potentially unethical decisions.
  • Detects different types of bias.
  • Provides fair recommendations.
  • Uses both traditional ML and transformer technology.
  • Provides an easy-to-use web interface.

12. Limitations

  • The dataset is relatively small and custom-built.
  • The system is an academic prototype.
  • Model confidence is not the same as calibrated probability.
  • The system may not handle every possible ethical situation.

13. Conclusion

The proposed NLP system demonstrates how Artificial Intelligence can assist in identifying potentially biased decisions and supporting fairer decision-making.

The system combines traditional machine learning with a transformer-based model and provides an interactive Flask interface for analyzing decision statements.
